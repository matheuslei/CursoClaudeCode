# Plugin taskflow (treino do curso)

Plugin de estudo do Módulo 8 do curso "Claude Code: do zero ao avançado". Junta num pacote as
peças criadas para o projeto de treino TaskFlow:

- skills `/taskflow:revisar-taskflow`, `/taskflow:nova-funcionalidade` e `/taskflow:padroes-taskflow`;
- subagente `taskflow:revisor-taskflow` (somente leitura);
- hook que confere a sintaxe dos `.py` do projeto depois de cada edição;
- servidor MCP `plugin:taskflow:tarefas` com as ferramentas de tarefas.

O servidor MCP precisa do pacote `mcp` no Python que estiver no PATH: abra o Claude Code com o
ambiente virtual do projeto ativado. Dados fictícios. Não publicado.
