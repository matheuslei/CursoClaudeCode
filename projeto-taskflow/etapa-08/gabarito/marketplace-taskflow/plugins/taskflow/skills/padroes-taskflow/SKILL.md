---
description: Padrões de código do TaskFlow (CLI de tarefas em Python). Use ao escrever ou alterar funções do TaskFlow.
---

Ao escrever código para o TaskFlow:

- Use só a biblioteca padrão do Python.
- Dê nomes em português às funções e variáveis.
- Escreva uma docstring curta de uma linha em cada função.
- Números de tarefa começam em 1; valide com `_indice_valido` antes de acessar a lista.
- Mensagens para o usuário em português.
- Use só dados fictícios em exemplos e testes.
