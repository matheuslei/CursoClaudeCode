| Arquivo | Texto para narrar |
|---|---|
| `m2a2-01.mp3` | Toda sessão começa do zero. O Claude ponto MD é o jeito de não repetir as mesmas instruções todo dia. |

| `m2a2-03.mp3` | O comando barra init analisa o projeto e gera um Claude ponto MD inicial. Se já existir um, ele sugere melhorias. Trate o resultado como rascunho e revise sempre. |

## m2a4: /clear, /compact e /rewind em 1 minuto

| Arquivo | Texto para narrar |
|---|---|
| `m2a4-01.mp3` | Três comandos, três situações: recomeçar, resumir ou voltar no tempo. |
| `m2a4-02.mp3` | Mudou de assunto? Use barra clear. O contexto fica vazio, mas o Claude ponto MD e a memória continuam. E a conversa anterior pode ser retomada com barra resume. |
| `m2a4-03.mp3` | Mesma tarefa, conversa longa? Use barra compact. Você pode dar foco ao resumo. Por exemplo: foque nos testes que falharam. |

| `m2a4-05.mp3` | Atenção: arquivos alterados só por comandos de terminal, ou fora do Claude Code, não são rastreados. Checkpoint é recuperação rápida. Não substitui o Git. |
| `m2a4-06.mp3` | Resumindo: assunto novo, barra clear. Mesma tarefa, barra compact. Caminho errado, barra rewind. |

## m6a1: O que é MCP em 1 minuto

| Arquivo | Texto para narrar |
|---|---|
| `m6a1-01.mp3` | Muito do seu trabalho está fora do código: tarefas, documentação, bancos de dados. O M C P liga o Claude a tudo isso. |
| `m6a1-02.mp3` | Pense numa tomada padrão. Um servidor M C P feito uma vez funciona no Claude Code, no app Desktop, no V S Code e em outros clientes compatíveis. |
| `m6a1-03.mp3` | Um servidor oferece ferramentas, que são ações que o Claude chama; recursos, que são dados que você menciona com arroba; e prompts, que viram comandos. |
| `m6a1-04.mp3` | Ele se conecta de dois jeitos: S T D I O, um programa que roda na sua máquina, ou H T T P, um serviço hospedado acessado por uma URL. |
| `m6a1-05.mp3` | Cada servidor ocupa um pouco do contexto. O tool search, ligado por padrão, só carrega as definições completas quando o Claude precisa. Mesmo assim, remova os que você não usa. |
| `m6a1-06.mp3` | E o mais importante: só conecte servidores confiáveis. Conteúdo externo pode esconder instruções maliciosas. Na empresa, isso é decisão da segurança da informação. |

## m6a2: Instalar um servidor MCP em 1 minuto

| Arquivo | Texto para narrar |
|---|---|
| `m6a2-01.mp3` | O fluxo é sempre o mesmo, para qualquer servidor: adicionar, conferir, usar e, se precisar, remover. |
| `m6a2-02.mp3` | Para um servidor hospedado, use claude M C P add com transporte H T T P, um nome que você escolhe e a URL. O servidor de documentação do Claude Code é um ótimo primeiro teste. |
| `m6a2-03.mp3` | Para um servidor local, o padrão é S T D I O. Tudo depois dos dois traços é o comando que inicia o servidor. Esquecer os dois traços é o erro mais comum. |
| `m6a2-04.mp3` | Confira com claude M C P list, que mostra o status de cada servidor. Dentro da sessão, o barra M C P abre o painel para autenticar e reconectar. |
| `m6a2-05.mp3` | O escopo define onde fica salvo: local, o padrão, só para você neste projeto; project, num arquivo ponto M C P ponto json que vai para o Git; ou user, para todos os seus projetos. |
| `m6a2-06.mp3` | Serviços com login usam claude M C P login. E servidores vindos de um ponto M C P ponto json pedem sua aprovação antes de rodar, para que um repositório clonado não execute nada sem você consentir. |

## m6a3: Criar um MCP em Python em 1 minuto

| Arquivo | Texto para narrar |
|---|---|
| `m6a3-01.mp3` | Com cerca de quarenta linhas de Python, você ensina o Claude a usar os seus próprios sistemas. |
| `m6a3-02.mp3` | Por que não rodar o script direto? Porque uma ferramenta M C P tem nome, descrição e parâmetros tipados. E você controla o que é permitido: aqui, só listar e adicionar. |
| `m6a3-03.mp3` | Crie um ambiente virtual e instale o pacote M C P. O S D K atual exige Python três ponto onze ou superior. Na máquina de trabalho, confirme com a TI antes de instalar. |
| `m6a3-04.mp3` | O código é simples. Você cria o servidor, marca cada função com o decorador tool, e roda com transporte S T D I O. A docstring vira a descrição que o Claude lê. |
| `m6a3-05.mp3` | Um cuidado importante: nunca use print num servidor S T D I O. A saída padrão é o canal do protocolo, e um print ali corrompe a comunicação. Devolva textos nas ferramentas. |
| `m6a3-06.mp3` | Para conectar, registre o servidor com claude M C P add, apontando o python do ambiente virtual e o arquivo do servidor. Depois confira com claude M C P list. |
