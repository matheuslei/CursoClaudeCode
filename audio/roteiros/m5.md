# Roteiro de narração · Módulo 5

| Arquivo | Texto para narrar |
|---|---|
| `m5a1-01.mp3` | Nesta aula, você vai descobrir onde cada configuração do Claude Code deve ficar e qual valor vale quando há conflito. |
| `m5a1-02.mp3` | O Claude ponto MD é orientação: o Claude lê e tenta seguir. Já o settings ponto json é aplicado pela própria ferramenta: permissões, hooks, modelo padrão e variáveis de ambiente. |
| `m5a1-03.mp3` | São três arquivos principais. O de usuário vale para todos os seus projetos. O de projeto é do time e vai para o Git. E o local é só seu, naquele projeto, e fica fora do Git. |
| `m5a1-04.mp3` | Quando a mesma chave aparece em mais de um lugar, vale a de nível mais alto. No topo, o gerenciado da organização. Depois, a linha de comando, o local, o projeto e, por último, o usuário. |
| `m5a1-05.mp3` | Três detalhes que confundem: listas como permissões se somam entre os arquivos. O JSON é estrito, sem comentários. E barra status mostra quais arquivos foram carregados. |
| `m5a1-06.mp3` | Resumindo: exceção sua vai no settings local. Regra do time vai no settings do projeto, commitado. |
| `m5a2-01.mp3` | Nesta aula, você vai transformar um pedido que você repete toda hora numa skill reutilizável. |
| `m5a2-02.mp3` | Sabe aquele pedido longo que você digita várias vezes? Revise o diff, confira os testes, sugira o commit. Uma skill guarda esse procedimento num arquivo, e você chama com um comando. |
| `m5a2-03.mp3` | Diferente do Claude ponto MD, que entra em toda sessão, o conteúdo completo da skill só entra no contexto quando ela é usada. |
| `m5a2-04.mp3` | Cada skill é uma pasta com um arquivo skill ponto MD. No topo, a description é a parte mais importante: é ela que o Claude lê para decidir quando usar a skill. E uma linha com exclamação roda um comando antes, como injetar o diff atual. |
| `m5a2-05.mp3` | Por padrão, tanto você quanto o Claude podem chamar a skill. Com disable model invocation, só você chama, bom para ações sensíveis. Com user invocable falso, só o Claude. |
| `m5a2-06.mp3` | Barra skills lista as disponíveis, e barra skill doctor mostra quanto contexto cada uma custa. Atenção: leia o conteúdo antes de instalar skills de terceiros. |
| `m5a2-07.mp3` | A regra é simples: repetiu o mesmo pedido? Transforme em skill. |
| `m5a3-01.mp3` | Nesta aula, você vai mudar o jeito como o Claude responde e colocar informações úteis no rodapé do terminal. |
| `m5a3-02.mp3` | Enquanto estuda, você quer explicações. No dia a dia, quer respostas diretas. Um output style troca o jeito do Claude para a sessão inteira, sem repetir o pedido em cada mensagem. |
| `m5a3-03.mp3` | Os estilos embutidos são: Default, o padrão. Proactive, que já começa a implementar. Concise, direto ao ponto. Explanatory, que explica o porquê. E Learning, que deixa pequenos trechos para você escrever. |
| `m5a3-04.mp3` | Para trocar, use barra output style e o nome do estilo. Para criar o seu, escreva um arquivo Markdown na pasta output styles. No terminal, reinicie o Claude Code depois de criar. |
| `m5a3-05.mp3` | A status line é uma barra no rodapé que mostra, sem você perguntar, dados como o modelo e quanto contexto já foi usado. O jeito mais fácil é pedir com barra statusline. |
| `m5a3-06.mp3` | E lembre: estilo muda como o Claude responde, mas é instrução, não garantia. O que precisa acontecer sempre vai num hook, o assunto da próxima aula. |
| `m5a4-01.mp3` | Nesta aula, você vai aprender a diferença entre pedir e garantir: os hooks. |
| `m5a4-02.mp3` | Escrever no Claude ponto MD para sempre verificar a sintaxe funciona na maioria das vezes, mas não sempre. Um hook é executado pela ferramenta, toda vez, sem exceção. |
| `m5a4-03.mp3` | Os hooks se prendem a eventos. Os mais usados: quando a sessão começa, quando você envia um prompt, antes de uma ferramenta rodar, que pode bloquear a ação, depois que ela rodou, e quando o Claude termina de responder. |
| `m5a4-04.mp3` | A configuração fica no settings, na chave hooks: evento, matcher e comando. Aqui, depois de cada Edit ou Write, o TaskFlow roda um script Python que verifica a sintaxe. |
| `m5a4-05.mp3` | O código de saída do seu script decide o que acontece. Zero segue normalmente. Dois é bloqueante: no Pre Tool Use impede a ação, e a mensagem vai para o Claude. Qualquer outro, como um, não bloqueia. |
| `m5a4-06.mp3` | Cuidado: hooks rodam comandos com as suas permissões, sem pedir aprovação. Leia todo hook de projeto ou plugin antes de confiar. Barra hooks mostra os configurados e de onde vêm. |
| `m5a4-07.mp3` | Guarde assim: pedir é Claude ponto MD. Garantir é hook. |
