# Roteiro de narração · Módulo 7

| Arquivo | Texto para narrar |
|---|---|
| `m7a1-01.mp3` | Nesta aula, você vai criar um ajudante especializado: um subagente que revisa o TaskFlow e devolve só o resumo. |
| `m7a1-02.mp3` | Quando o Claude lê dezenas de arquivos para responder, tudo isso ocupa a sua janela de contexto. Um subagente trabalha numa janela própria e devolve só o resultado. |
| `m7a1-03.mp3` | Cada subagente é um arquivo Markdown na pasta ponto claude barra agents. No topo, o nome e a description, que diz quando usar. Tools limita as ferramentas. O resto do arquivo são as instruções. |
| `m7a1-04.mp3` | Você aciona pelo nome, num pedido normal, ou com arroba agent, hífen e o nome. O Claude também delega sozinho quando a description combina com o pedido. |
| `m7a1-05.mp3` | E alguns já vêm prontos: o Explore, que busca no código só lendo, o Plan, que pesquisa no modo de planejamento, e o general purpose, para tarefas com várias etapas. |
| `m7a1-06.mp3` | Mas nem tudo vale delegar. Mudança pequena e conversa de vai e volta ficam aqui. Cada subagente começa sem contexto e gasta os próprios tokens. |
| `m7a2-01.mp3` | Nesta aula, você vai deixar o Claude trabalhando enquanto continua conversando: segundo plano e fork. |
| `m7a2-02.mp3` | Um comando demorado ou um subagente ocupando a tela? Aperte control B. O trabalho vai para o segundo plano e você volta a digitar. |
| `m7a2-03.mp3` | O comando barra tasks mostra o que está rodando e o que terminou. Para parar todos os subagentes em segundo plano, control X e depois control K, duas vezes. |
| `m7a2-04.mp3` | Fork é copiar a conversa. Barra fork cria uma sessão paralela, barra branch troca para uma ramificação, e barra subtask manda um subagente com todo o histórico. |
| `m7a2-05.mp3` | Lembre: cada trabalho paralelo gasta os próprios tokens. Paralelize o que é independente, e confira o custo com barra usage. |
| `m7a3-01.mp3` | Nesta aula, duas sessões do Claude vão mexer no mesmo projeto ao mesmo tempo, sem uma atropelar a outra. |
| `m7a3-02.mp3` | O problema: duas sessões editando a mesma pasta. Uma salva por cima da outra, e os testes de uma quebram por causa da outra. |
| `m7a3-03.mp3` | A solução é o worktree do Git: uma segunda pasta de trabalho, com a sua própria branch, ligada ao mesmo repositório. |
| `m7a3-04.mp3` | Com claude, hífen hífen worktree e um nome, o Claude Code cria a pasta em ponto claude barra worktrees e a branch worktree hífen nome. |
| `m7a3-05.mp3` | Cada sessão faz a sua parte em arquivos diferentes. No fim, você junta as branches com git merge e roda os testes. |
| `m7a3-06.mp3` | Ao sair, se o worktree não tem mudanças, ele pode ser removido sozinho. Se tem, o Claude pergunta se você quer manter. |
| `m7a4-01.mp3` | Nesta aula: acompanhar várias sessões numa tela só, e deixar o Claude trabalhando até cumprir um objetivo. |
| `m7a4-02.mp3` | O comando claude agents abre o agent view: uma lista das sessões em segundo plano, mostrando quem trabalha, quem espera você e quem terminou. |
| `m7a4-03.mp3` | Para criar uma sessão em segundo plano, use claude hífen hífen bg com o pedido. Dentro de uma sessão aberta, barra bg manda ela para lá. |
| `m7a4-04.mp3` | Já o barra goal define uma condição de término. Depois de cada turno, um modelo avaliador lê a conversa e decide se a condição foi cumprida. |
| `m7a4-05.mp3` | Escreva uma condição verificável, com prova na conversa e um limite de turnos. E barra goal clear cancela quando quiser. |
| `m7a5-01.mp3` | Última aula do módulo: escolher o jeito certo de orquestrar vários agentes. |
| `m7a5-02.mp3` | São três níveis. Subagentes dentro de uma sessão. Várias sessões em paralelo, cada uma no seu worktree. E equipes de agentes, que conversam entre si. |
| `m7a5-03.mp3` | As equipes de agentes são experimentais. Uma sessão líder cria colegas, divide uma lista de tarefas, e eles trocam mensagens diretamente. |
| `m7a5-04.mp3` | Mas cada colega é uma sessão inteira, com contexto e tokens próprios. Comece com três a cinco, e prefira tarefas de pesquisa e revisão. |
| `m7a5-05.mp3` | A regra de ouro: use o nível mais simples que resolve. Só suba quando o paralelismo realmente compensar. |
