# Roteiro de narração · Módulo 8

| Arquivo | Texto para narrar |
|---|---|
| `m8a1-01.mp3` | Nesta aula, você vai entender o que é um plugin, e como instalar um sem levar surpresa junto. |
| `m8a1-02.mp3` | Um plugin é uma pasta que junta skills, subagentes, hooks e servidores MCP, e instala tudo de uma vez. |
| `m8a1-03.mp3` | Os plugins vêm de marketplaces, que são catálogos. O oficial da Anthropic já vem adicionado. O comando barra plugin abre o gerenciador. |
| `m8a1-04.mp3` | Na instalação, você escolhe o escopo: só para você, para todo o projeto, ou só para você neste projeto. |
| `m8a1-05.mp3` | Atenção: um plugin roda código com as suas permissões, e ocupa contexto em toda sessão. Leia os detalhes antes de instalar. |
| `m8a2-01.mp3` | Nesta aula, as peças soltas do TaskFlow viram um único plugin. |
| `m8a2-02.mp3` | O plugin precisa de uma pasta ponto claude hífen plugin com o arquivo plugin ponto JSON. É o manifesto, e só o nome é obrigatório. |
| `m8a2-03.mp3` | As peças ficam na raiz do plugin: skills, agents, a pasta hooks, e o arquivo ponto mcp ponto JSON. |
| `m8a2-04.mp3` | Para testar sem instalar, use claude hífen hífen plugin hífen dir. Editou? Rode barra reload hífen plugins. |
| `m8a2-05.mp3` | No plugin, tudo ganha o prefixo do nome. A skill vira barra taskflow, dois pontos, revisar hífen taskflow. |
| `m8a2-06.mp3` | Antes de usar, valide com claude plugin validate. Ele aponta o campo errado e mostra o que o plugin fornece. |
| `m8a3-01.mp3` | Carregar não é funcionar. Nesta aula, você mede se o plugin muda mesmo o comportamento do Claude. |
| `m8a3-02.mp3` | Cada caso de avaliação tem um pedido e alguns graders: verificações de passa ou falha, como uma expressão regular ou um juiz. |
| `m8a3-03.mp3` | O comando claude plugin eval roda cada caso com o plugin e sem ele. A diferença entre as notas é o que o plugin acrescentou. |
| `m8a3-04.mp3` | Cuidado com o custo: cada rodada é uma chamada real ao modelo. Para iterar, rode um caso só, uma vez, só com o plugin. |
| `m8a3-05.mp3` | Diferença perto de zero e a skill não foi usada? Melhore a description da skill e rode de novo. |
| `m8a4-01.mp3` | Para fechar o módulo, você vai instalar o seu plugin pelo nome, a partir de um marketplace na sua própria máquina. |
| `m8a4-02.mp3` | Um marketplace é uma pasta com o arquivo marketplace ponto JSON, que lista os plugins e onde buscar cada um. |
| `m8a4-03.mp3` | Adicione com claude plugin marketplace add e o caminho da pasta. Depois, instale com taskflow, arroba, e o nome do marketplace. |
| `m8a4-04.mp3` | Para outras pessoas, o mesmo catálogo iria para um repositório. No curso, nada é publicado. Remover o marketplace desinstala os plugins dele. |
