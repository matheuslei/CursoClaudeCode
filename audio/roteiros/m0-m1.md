Mesmo formato de `../ROTEIRO-NARRACAO.md`. Gere com `python gerar_audios.py --so <id>`.

## Aula 0.1: Terminal em 20 minutos (7 cenas)

| Arquivo | Texto para narrar |
|---|---|
| `m0a1-01.mp3` | Nesta aula você vai perder o medo do terminal: o mínimo para usar o Claude Code com tranquilidade. |
| `m0a1-02.mp3` | O terminal é uma conversa de texto com o computador. Você digita um comando, o shell interpreta, o sistema executa e a resposta aparece na tela. |
| `m0a1-03.mp3` | No Windows usamos o PowerShell. O prompt começa com P S e mostra em qual pasta você está. |
| `m0a1-04.mp3` | Cinco comandos resolvem quase tudo: P W D mostra onde você está, L S lista o conteúdo, C D entra numa pasta, M K dir cria uma pasta, e cat mostra um arquivo. |

| `m0a1-06.mp3` | E atenção: Remove Item apaga de verdade, sem passar pela Lixeira. Quando o Claude pedir para rodar um comando assim, leia antes de aprovar. |
| `m0a1-07.mp3` | Resumindo: entender o terminal é entender o que o Claude está fazendo por você. |

## Aula 0.2: Git essencial (6 cenas)

| Arquivo | Texto para narrar |
|---|---|
| `m0a2-01.mp3` | O Git é a sua rede de segurança para trabalhar com inteligência artificial sem medo. |
| `m0a2-02.mp3` | Um agente edita vários arquivos em segundos. Às vezes acerta em cheio, às vezes não. O Git guarda cada versão do projeto, e você sempre pode voltar ao último ponto bom. |
| `m0a2-03.mp3` | O Git tem três áreas. Você edita na pasta de trabalho, escolhe o que vai salvar com git add, e grava uma versão no histórico com git commit. |

## Aula 1.3: Comandos com barra (7 cenas)

| Arquivo | Texto para narrar |
|---|---|
| `m1a3-01.mp3` | Tudo o que você digita vai para o Claude, exceto o que começa com barra: esses comandos controlam a própria ferramenta. |
| `m1a3-02.mp3` | Não precisa decorar. Digite barra e uma lista aparece. Continue digitando para filtrar, e Tab completa. |
| `m1a3-03.mp3` | Para monitorar: barra context mostra o uso do contexto, barra usage mostra custo e limites, e barra status confere o ambiente. |
| `m1a3-04.mp3` | Para ajustar: barra model troca o modelo, e barra effort muda o nível de raciocínio. Tarefa simples, modelo e esforço menores. |
| `m1a3-05.mp3` | Para corrigir o rumo, barra rewind volta a um ponto anterior. Barra compact resume e continua a mesma tarefa. E barra clear começa uma conversa nova. |
| `m1a3-06.mp3` | E no PowerShell: claude traço c continua a última conversa, traço r escolhe qual retomar, e traço p responde e sai, ótimo para scripts. |
| `m1a3-07.mp3` | Regra prática: uma tarefa, uma conversa. |
