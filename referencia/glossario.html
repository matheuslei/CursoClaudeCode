Glossário

Os termos do curso explicados em uma ou duas frases.

Agente de IA
Um modelo de linguagem que, além de conversar, usa ferramentas (ler arquivos, rodar comandos, editar código) em ciclos até cumprir um objetivo.
Loop agêntico
O ciclo que o Claude repete: reunir contexto → agir → verificar o resultado → decidir o próximo passo.
Ferramenta (tool)
Uma ação que o Claude pode executar, como Read (ler arquivo), Edit (editar), Bash/PowerShell (rodar comando) ou WebFetch (ler página).
Janela de contexto
Tudo o que o modelo "enxerga" de uma vez: instruções, CLAUDE.md, mensagens, arquivos lidos e saídas de comandos. É medida em tokens e tem limite.
Token
Pedaço de texto que o modelo processa (aproximadamente ¾ de uma palavra em inglês; em português costuma ser um pouco menos). Custo e limites são medidos em tokens.
CLAUDE.md
Arquivo Markdown na raiz do projeto com instruções permanentes (comandos, padrões, regras). O Claude lê no início de toda sessão. Criado com /init.
Auto memory
Memória que o próprio Claude grava entre sessões com aprendizados sobre o projeto. Gerenciada com /memory.
Modo de permissão
Define o que o Claude pode fazer sem perguntar. Exemplos: Manual (pergunta antes de editar ou rodar), acceptEdits (edita sem perguntar), plan (só analisa e planeja), auto (um classificador decide o que é seguro).
Plan mode
Modo em que o Claude investiga e propõe um plano sem alterar arquivos. Você aprova antes da execução.
Checkpoint
Ponto salvo automaticamente antes das edições do Claude. Com /rewind (ou Esc Esc) você volta a ele.
Compactação
Resumir a conversa para liberar espaço no contexto (/compact). Acontece também automaticamente quando o contexto enche.
Esforço (effort)
Quanto o modelo "pensa" antes de responder: low, medium, high, xhigh, max. Mais esforço = respostas mais cuidadosas, porém mais lentas e caras.
Skill
Pacote de instruções reutilizáveis que o Claude carrega quando a tarefa pede (ex.: um fluxo de revisão do seu time). Vira um comando /nome.
Subagente
Um "ajudante" com contexto próprio que o Claude dispara para uma subtarefa (ex.: pesquisar no código) e que devolve só o resumo.
Hook
Comando que roda automaticamente antes ou depois de uma ação do Claude (ex.: formatar o código após cada edição).
MCP (Model Context Protocol)
Padrão aberto para conectar o Claude a ferramentas e dados externos (Jira, Google Drive, bancos de dados, APIs próprias).
Plugin
Pacote distribuível que junta skills, subagentes, hooks e servidores MCP para instalar de uma vez.
Segundo plano (background)
Trabalho que continua rodando enquanto você conversa: comandos e subagentes. Acompanhe com /tasks; mande com Ctrl+B.
Fork
Cópia da conversa num ponto, para seguir outro caminho sem perder o original (/branch, /fork, /subtask). Copia o histórico, não os arquivos.
Agent view
Tela que lista as sessões em segundo plano e o estado de cada uma (claude agents). Em research preview.
Agent teams (equipe de agentes)
Recurso experimental: uma sessão líder cria colegas que dividem uma lista de tarefas e trocam mensagens entre si.
/goal
Condição de término: o Claude segue turno a turno até um avaliador, que lê a conversa, confirmar que ela foi cumprida.
Plugin
Pasta com manifesto (.claude-plugin/plugin.json) que junta skills, subagentes, hooks e servidores MCP e instala tudo como uma unidade. As peças ganham o prefixo do plugin.
Marketplace
Catálogo (.claude-plugin/marketplace.json) que lista plugins e onde buscar cada um. Pode ser um repositório ou uma pasta local.
Eval (avaliação de plugin)
Casos de teste rodados com e sem o plugin para medir o que ele acrescenta (claude plugin eval).
Modo não interativo (-p)
Execução sem conversa: o Claude responde e termina. Usado em scripts e CI.
Bare mode
Início mínimo, sem hooks, skills, MCP nem CLAUDE.md; exige chave de API.
claude-code-action
A action oficial do Claude Code para o GitHub Actions.
GitHub Secrets
Cofre de segredos do repositório no GitHub. Chaves nunca vão no código.
Cron
Expressão de horário com 5 campos, usada em agendamentos.
Agent SDK
Biblioteca (claude-agent-sdk em Python) para construir agentes próprios com o mesmo loop do Claude Code.
query() e ClaudeSDKClient
No Agent SDK: query() roda um pedido e devolve mensagens; ClaudeSDKClient mantém uma conversa contínua.
Ferramenta própria (@tool)
Função Python exposta ao agente por um servidor MCP no próprio processo (create_sdk_mcp_server).
can_use_tool
Função do Agent SDK que decide, a cada chamada, se o agente pode usar uma ferramenta.
Worktree
Recurso do Git para ter várias cópias de trabalho do mesmo repositório em pastas diferentes; permite rodar sessões em paralelo sem conflito.
Repositório (repo)
Pasta de projeto controlada pelo Git, com todo o histórico de mudanças.
Commit
Uma "foto" salva das mudanças, com mensagem descritiva. É seu ponto de retorno seguro.
Branch
Linha paralela de desenvolvimento no Git. Permite experimentar sem mexer na versão principal.
Diff
A diferença entre duas versões de um arquivo: o que entrou e o que saiu.
PowerShell
O terminal e linguagem de comandos padrão do Windows moderno. O prompt começa com PS C:\.
PATH
Lista de pastas onde o sistema procura programas. Se claude "não é reconhecido", a pasta de instalação não está no PATH.
Spec-Driven Development (SDD)
Escrever a especificação (o quê, por quê, critérios de aceite) antes de pedir o código. Reduz retrabalho e mal-entendidos com a IA.
Prompt
A mensagem/instrução que você envia ao modelo.
Alucinação
Quando o modelo afirma algo plausível, mas falso. Por isso sempre verificamos (testes, execução, leitura do diff).
