Cola de comandos

Tudo o que você usa no dia a dia, num só lugar. Digite para filtrar.

No terminal (antes de abrir o Claude)

ComandoO que faz
irm https://claude.ai/install.ps1 | iexInstala o Claude Code no Windows (PowerShell). Atualiza sozinho.
winget install Anthropic.ClaudeCodeInstalação alternativa via WinGet. Não atualiza sozinho: use winget upgrade Anthropic.ClaudeCode.
claude --versionConfere se a instalação funcionou.
claudeAbre uma sessão interativa na pasta atual.
claude "tarefa"Abre a sessão já com um pedido inicial.
claude -p "pergunta"Modo não interativo: responde e sai. Bom para scripts.
claude -cContinua a conversa mais recente desta pasta.
claude -rEscolhe uma conversa anterior para retomar.
claude -w nomeAbre uma sessão num worktree próprio (.claude/worktrees/nome, branch worktree-nome). Precisa de Git. Módulo 7.
claude --bg "tarefa"Cria uma sessão já em segundo plano. Módulo 7.
claude agentsAbre o agent view com as sessões em segundo plano (research preview). Módulo 7.
git worktree listLista os worktrees do repositório.
claude plugin listLista plugins instalados, escopo e status. Módulo 8.
claude plugin validate .Confere manifesto, frontmatter e catálogo de um plugin ou marketplace. Módulo 8.
claude --plugin-dir .\meu-pluginCarrega um plugin só nesta sessão, sem instalar. Módulo 8.
claude plugin eval .Avalia o comportamento do plugin com e sem ele. Gasta uso do plano. Módulo 8.
claude plugin marketplace add .\pastaRegistra um marketplace local. Módulo 8.
claude -p "pedido"Modo não interativo: responde e termina. Para scripts. Módulo 9.
claude -p "pedido" --output-format jsonSaída em JSON com resultado, sessão e custo (total_cost_usd). Módulo 9.
claude -p "pedido" --max-budget-usd 1Para quando o gasto estimado chega ao valor (modo print). Módulo 9.
Get-Content arq | claude -p "resuma"Envia conteúdo pelo pipe no PowerShell. Módulo 9.
pip install claude-agent-sdkInstala o Agent SDK para Python (3.10+), dentro de um ambiente virtual. Módulo 10.
$env:ANTHROPIC_API_KEY = "sua-chave-aqui"Define a chave só nesta sessão do terminal (nunca no código). Módulo 10.
claude --safe-modeAbre sem nenhuma personalização. Útil para diagnosticar problemas.

Dentro da sessão: comandos com /

ComandoO que faz
/helpMostra ajuda e comandos disponíveis.
/initCria o CLAUDE.md, o guia do projeto que o Claude lê em toda sessão.
/clearComeça uma conversa nova, com contexto vazio. A anterior pode ser retomada com /resume.
/compact [instruções]Resume a conversa para liberar contexto e continuar a mesma tarefa.
/contextMostra quanto da janela de contexto está em uso.
/rewindVolta a conversa e/ou o código para um ponto anterior (checkpoint).
/resumeAbre a lista de conversas anteriores para retomar.
/modelTroca o modelo (e salva como padrão).
/effortAjusta o nível de esforço: de low a xhigh, max ou auto.
/plan [tarefa]Entra no plan mode: o Claude analisa e planeja antes de editar.
/usageCusto da sessão, limites do plano e estatísticas. Alias: /cost.
/statusVersão, modelo, conta e conectividade.
/doctorCheckup da instalação e das configurações.
/permissionsGerencia regras de permissão (allow, ask, deny).
/memoryEdita arquivos CLAUDE.md e a memória automática.
/diffRevisa as mudanças feitas na pasta, inclusive as do Claude.
/copyCopia a última resposta para a área de transferência.
/exportExporta a conversa como texto.
/configAbre as configurações.
/powerupLições interativas oficiais dentro da ferramenta.
/tasksMostra e gerencia o trabalho em segundo plano (também /bashes).
/branch · /fork · /subtaskRamifica a conversa · copia para uma sessão paralela · subagente com o histórico.
/bgManda a sessão aberta para segundo plano (agent view).
/goal condiçãoTrabalha turno a turno até a condição ser cumprida. /goal clear cancela.
/list-agentsLista com quem a sessão pode trocar mensagens (também /peers), quando disponível.
/pluginGerenciador de plugins: descobrir, instalar, ativar, remover, marketplaces e erros.
/reload-pluginsRecarrega plugins depois de editar ou instalar.
/code-reviewProcura bugs nas mudanças (níveis low a max; --fix aplica). Alias /review.
/security-reviewRevisão de segurança das mudanças.
/install-github-appConfigura o app do GitHub e os workflows do Claude Code.
/loop [intervalo] [pedido]Repete um pedido enquanto a sessão está aberta.
/scheduleTarefas agendadas na nuvem (research preview). Alias /routines.
/exitSai do Claude Code (ou Ctrl+D duas vezes).

Atalhos de teclado

AtalhoO que faz
EscInterrompe o Claude no meio da resposta (o trabalho feito até ali fica).
Esc EscCom texto: limpa o rascunho. Com campo vazio: abre o menu de rewind.
Shift+TabAlterna o modo de permissão (Manual, acceptEdits, plan, e outros quando disponíveis). No Windows, Alt+M em alguns terminais.
Ctrl+CInterrompe; com nada rodando, limpa o campo; duas vezes, sai.
Ctrl+RBusca no histórico de comandos.
↑ / ↓Navega no histórico de mensagens.
Ctrl+J ou \+EnterQuebra de linha (prompt com várias linhas). No Windows Terminal recente, Shift+Enter também.
Alt+VCola imagem da área de transferência (Windows).
Alt+PTroca de modelo sem apagar o que você está digitando.
Ctrl+OAbre o visualizador detalhado da conversa (ferramentas usadas).
Ctrl+BManda comando ou agente em execução para segundo plano.
Ctrl+X Ctrl+KPara todos os subagentes em segundo plano (aperte duas vezes em até 3 s).
Ctrl+TMostra ou esconde a lista de tarefas do Claude.
Ctrl+GEdita o prompt no seu editor de texto padrão.
? (campo vazio)Mostra o painel de atalhos.

Prefixos especiais

PrefixoO que faz
/Comandos e skills.
!Shell mode: roda o comando direto, adiciona a saída ao contexto e o Claude comenta o resultado. Ex.: ! git status.
@Menciona um arquivo com autocompletar. Ex.: explique @tarefas.py.

Conferido em 17/11/2026 com a documentação oficial (Commands e Interactive mode). Comandos mudam com frequência: confirme com /help na sua versão.
