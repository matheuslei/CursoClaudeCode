Instalar e conferir

irm https://claude.ai/install.ps1 | iex # PowerShell claude --version # terminal NOVO cd ~\estudos-claude\taskflow claude # login na 1ª vez
  • "não é reconhecido" → abra um terminal novo
  • "irm not recognized" → você está no CMD

O ciclo de uma sessão

📂 cd + claude → ❓ explorar → ✍ pedir → 🔐 aprovar → ✅ verificar → 💾 commit

Permissões

  • Yes: só esta ação
  • Yes, don't ask again…: esta e as parecidas
  • No + instrução: recusa e redireciona
  • Leia o diff/comando antes de aprovar
  • Shift+Tab alterna o modo de permissão

Comandos-chave

  • /clear: tarefa nova · /compact: mesma tarefa, resumida
  • /rewind: voltar conversa/código · /resume: retomar
  • /context · /usage · /status · /doctor
  • /model · /effort

No PowerShell

  • claude "pedido": abre com pedido
  • claude -c: continua a última
  • claude -r: escolhe qual retomar
  • claude -p "pergunta": responde e sai

Prefixos e atalhos

  • / comandos · ! shell direto · @ arquivo
  • Esc interrompe · EscEsc rewind/limpa
  • Ctrl+J nova linha · Alt+V colar imagem
  • ? mostra todos os atalhos

O prompt que funciona
