Base: terminal, Git e agentes

Use ← → para navegar · F para tela cheia · Ctrl+P para salvar em PDF

Terminal: se localizar

  • pwd: onde estou?
  • ls: o que tem aqui?
  • cd pasta / cd ..: entrar e voltar
  • mkdir, ni, cat: criar pasta, criar arquivo, ler
  • Tab completa, ↑ repete

Cuidado com o que apaga

Remove-Item -Recurse .\dados
  • Apaga a pasta e tudo dentro
  • Não vai para a Lixeira
  • Leia todo comando antes de aprovar para o Claude

Git: o ciclo de segurança

git status # o que mudou? git diff # quais linhas? git add arquivo # preparar git commit -m "..." # salvar versão git restore arquivo # desfazer o que não presta

Regra de ouro

Commit antes de pedir mudança grande.
Diff depois, para revisar.

Chat × Agente

  • Chat: você copia e cola, testa, cola o erro…
  • Agente: lê, edita, roda, verifica e repete sozinho
  • Seu papel muda: especificar, supervisionar, revisar

O loop agêntico

🎯 Objetivo → 🔎 Contexto → 🛠 Ação → ✅ Verificação → 🔁

Interrompa com Esc a qualquer momento para corrigir o rumo.

As 4 peças

  • 🧠 Modelo: o raciocínio (/model)
  • 🧰 Ferramentas: ler, editar, rodar, buscar
  • 📚 Contexto: o que ele enxerga (limitado!)
  • 🔐 Permissões: o que faz sem perguntar
