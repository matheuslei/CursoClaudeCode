Subagente em uma frase

Um ajudante com janela de contexto própria, que faz o trabalho pesado e devolve só o resultado.

  • Arquivo em .claude/agents/<nome>.md (projeto) ou ~/.claude/agents/ (seu)
  • name e description obrigatórios; tools omitido = herda tudo
  • Acionar: pelo nome, @agent-<nome> ou automático pela description
  • Primeiro arquivo numa pasta agents nova: reinicie a sessão

Delegar ou fazer aqui?

  • ✅ Delegar: muita leitura, busca ampla, checklist repetida
  • ✋ Aqui: mudança pequena, vai e volta, pergunta sobre a conversa (/btw)
  • Prontos: Explore, Plan, general-purpose

Segundo plano e fork

  • Ctrl+B manda para segundo plano · /tasks acompanha · Ctrl+X Ctrl+K para todos
  • /branch: ramifica e troca · /fork: cópia em sessão paralela · /subtask: subagente com histórico
  • Fork copia a conversa, não os arquivos

Worktrees

claude -w exportar # .claude/worktrees/exportar · branch worktree-exportar claude -w estatisticas # em outro terminal git merge worktree-exportar git merge worktree-estatisticas python -m unittest

Precisa de Git · um arquivo, um dono · remover com mudanças apaga o trabalho

Agent view

  • claude agents: todas as sessões em segundo plano (research preview)
  • claude --bg "pedido" · /bg · ← com o campo vazio
  • Espaço espia · Enter entra · Ctrl+X para

/goal

/goal python -m unittest mostra OK nesta conversa, ou pare após 15 turnos
  • O avaliador só lê a conversa: a prova precisa aparecer nela
  • Fim mensurável + prova + restrições + limite
  • /goal mostra o status · /goal clear cancela

Três níveis de orquestração

  • 🤖 Subagentes: tarefa focada, só o resultado importa (mais barato)
  • 📁 Sessões paralelas: mudanças independentes, uma por worktree
  • 👥 Equipe de agentes: discussão entre colegas (experimental, CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1)
  • Regra de ouro: o nível mais simples que resolve · meça com /usage
