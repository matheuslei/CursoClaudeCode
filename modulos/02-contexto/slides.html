Contexto é tudo

Use ← → para navegar · F para tela cheia · Ctrl+P para salvar em PDF

A janela de contexto

  • Tudo o que o Claude "sabe" agora, medido em tokens
  • Já começa ocupada: system prompt, ferramentas, CLAUDE.md, memória
  • O que mais pesa: arquivos lidos, saídas, respostas longas
  • Perto do limite: compactação automática
  • Medir: /context · /context all

CLAUDE.md: onde mora

  • ~/.claude/CLAUDE.md: você, todos os projetos
  • ./CLAUDE.md: o projeto, vai para o Git
  • ./CLAUDE.local.md: você neste projeto (.gitignore)
  • Todos são somados; /init cria o rascunho

CLAUDE.md: como escrever

  • Concreto: "Rode python -m unittest", não "teste bem"
  • Curto: menos de 200 linhas
  • Imports: @README.md (até 4 níveis)
  • É contexto, não trava. Para bloquear: permissões e hooks
  • Nunca segredos

Memória automática

  • Escrita pelo Claude: user, feedback, project, reference
  • ~/.claude/projects/<projeto>/memory/MEMORY.md
  • Local da máquina, não vai para o Git
  • "Lembre que…" → memória · "Adicione ao CLAUDE.md" → CLAUDE.md
  • /memory: revisar, editar, ligar e desligar

Recomeçar, resumir, voltar

  • /clear: assunto novo (o anterior fica no /resume)
  • /compact foque em…: mesma tarefa, conversa longa
  • /rewind ou EscEsc: volta código e/ou conversa
  • Regra: uma tarefa, uma conversa

Limites do rewind

  • Rastreia as edições feitas pelas ferramentas do Claude
  • Não rastreia arquivos alterados só por comandos
  • Não rastreia mudanças feitas fora do Claude Code
  • Checkpoint é para a sessão; Git é para sempre

Os botões do custo

  • Modelo: haiku · sonnet (dia a dia) · opus (complexo) · fable
  • Esforço: /effort low … max
  • Contexto: enxuto = barato
  • Velocidade: /fast, mesmo modelo, mais rápido, mais caro
  • Acompanhe: /usage
