claude -p em uma frase

Pedido entra, o Claude trabalha sem conversa, a resposta sai e o processo termina.

git diff | claude -p "aponte erros" --max-turns 3 > r.txt $r = claude -p "..." --output-format json | ConvertFrom-Json # .result .session_id .total_cost_usd

Freios do modo -p

  • --allowedTools "Read,Grep": libera só o necessário (o resto que pede aprovação é negado)
  • --max-turns e --max-budget-usd: limites de turnos e de gasto estimado
  • --output-format json / stream-json · --json-schema → structured_output
  • --bare exige ANTHROPIC_API_KEY: não usa o login da assinatura

Revisão de código

  • /code-review [low…max] [--fix] [alvo]: bugs, em subagente de segundo plano
  • /security-review: vulnerabilidades, compara com origin/HEAD (precisa de origin)
  • Subagente revisor: regras do seu projeto · /simplify: só limpeza
  • Commit antes do --fix · ultra roda na nuvem

GitHub Actions

- uses: anthropics/claude-code-action@v1 with: anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }} prompt: "Revise ... seguindo o CLAUDE.md" claude_args: "--max-turns 10 --allowedTools Read,Grep,Glob"

Sem prompt: responde a @claude · com prompt: roda no evento

Segredos e custo no CI

  • 🔐 Chave só em GitHub Secrets. Vazou? Revogue.
  • 🪙 Duas contas: minutos do GitHub + tokens do Claude
  • Limites: --max-turns, timeout-minutes, concurrency, permissões mínimas
  • Treino: YAML conferido no PC; GitHub só em repositório pessoal de teste

/loop

  • /loop 5m pedido · /loop pedido (ritmo do Claude) · /loop (manutenção ou .claude/loop.md)
  • Só com a sessão aberta e ociosa · expira em 7 dias · mínimo 1 minuto
  • Parar: Esc no ritmo próprio · "cancele o loop" no intervalo fixo

Onde agendar?

  • ⏰ /loop: na sessão, para acompanhar algo agora
  • 💻 Desktop: no seu PC ligado, com arquivos locais, sem sessão aberta
  • ☁ Nuvem (/schedule, research preview): sem o seu PC, num clone do GitHub
  • 🐙 Actions: on: schedule no CI do repositório
  • 🎯 /goal não é agendamento: trabalha até uma condição
