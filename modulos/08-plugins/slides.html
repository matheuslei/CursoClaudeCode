Plugin em uma frase

Uma pasta que junta skills, subagentes, hooks e servidores MCP e instala tudo como uma unidade.

  • Vem de um marketplace (catálogo); o oficial é claude-plugins-official
  • Use quando várias peças andam juntas ou vão para vários projetos

Instalar com cuidado

  • /plugin: Discover · Installed · Marketplaces · Errors
  • Leia Will install e Context cost antes
  • Escopos: usuário · projeto · local
  • Plugin roda código com as suas permissões, fora do sandbox

Estrutura

taskflow/ .claude-plugin/plugin.json ← só ele aqui skills/<nome>/SKILL.md agents/*.md hooks/hooks.json .mcp.json

${CLAUDE_PLUGIN_ROOT} · ${CLAUDE_PROJECT_DIR}

Desenvolver

claude plugin validate .\taskflow claude --plugin-dir .\taskflow /reload-plugins claude plugin details taskflow

Nomes: /taskflow:revisar-taskflow · taskflow:revisor-taskflow · plugin:taskflow:tarefas

Avaliar

  • evals/<caso>/prompt.md + graders/*.md
  • Grátis: regex, tool_used, tool_order, file_exists · Pagos: llm, baseline
  • WITH − W/OUT = Δ (o que o plugin acrescenta)
  • Barato: --case x --runs 1 --ablation none · teto: --max-cost-usd

Marketplace local

claude plugin marketplace add .\marketplace-taskflow claude plugin install taskflow@treino-taskflow --scope local claude plugin marketplace remove treino-taskflow
