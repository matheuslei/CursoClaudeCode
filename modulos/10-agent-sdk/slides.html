Agent SDK em uma frase

O motor do Claude Code (loop, ferramentas, contexto) como biblioteca, dentro do seu programa Python.

  • Pacote claude-agent-sdk · Python 3.10+ · chave em ANTHROPIC_API_KEY, só no terminal
  • Login do claude.ai não serve: chave de API (ou Bedrock, Google Cloud, Foundry)
  • 🪙 Cobrado por uso · na empresa, só com aval da segurança da informação

O loop

async for m in query(prompt="...", options=ClaudeAgentOptions(...)): ... # SystemMessage → AssistantMessage → UserMessage → ResultMessage
  • Turno = o Claude responde; se pediu ferramentas, o SDK roda e devolve
  • ResultMessage: subtype, result (só no success), num_turns, total_cost_usd, session_id
  • Conversa contínua: ClaudeSDKClient + receive_response()

Opções essenciais

  • system_prompt · cwd · model (alias ou ID) · effort
  • allowed_tools pré-aprova · disallowed_tools / tools tiram
  • Travas: max_turns e max_budget_usd
  • Streaming: include_partial_messages=True + StreamEvent

Ferramentas próprias

@tool("adicionar_tarefa", "Adiciona uma tarefa…", {"titulo": str}) async def adicionar_tarefa(args): return {"content": [{"type": "text", "text": "ok"}]} SERVIDOR = create_sdk_mcp_server(name="taskflow", version="1.0.0", tools=[adicionar_tarefa]) ClaudeAgentOptions(mcp_servers={"taskflow": SERVIDOR}, allowed_tools=["mcp__taskflow__*"])

Nome completo mcp__servidor__ferramenta · erro previsto: is_error · servidor roda no seu processo

Quem decide se a ferramenta roda

  • Ordem: hooks → negar → perguntar → modo → permitir → can_use_tool
  • Modos: default · dontAsk · acceptEdits · plan · auto · bypassPermissions (só isolado)
  • Aprovado antes nunca chega ao callback

Callback e hooks

  • can_use_tool → PermissionResultAllow(updated_input=...) ou PermissionResultDeny(message=...)
  • HookMatcher(matcher="...", hooks=[...]) · PreToolUse nega com permissionDecision: "deny" (vale até no bypass)
  • PostToolUse para auditoria · hooks não gastam contexto

Subagentes e custo

  • agents={"revisor": AgentDefinition(description, prompt, tools, model)} + ferramenta Agent
  • total_cost_usd: estimativa local, inclui subagentes · fatura no console da conta
  • usage não inclui subagentes · com o cliente, o custo já é acumulado
  • Retomar: resume=session_id
