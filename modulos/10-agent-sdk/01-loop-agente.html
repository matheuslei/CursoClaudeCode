O loop do agente

Objetivo: instalar o Claude Agent SDK em Python, escrever um agente que lê o TaskFlow com query(), entender cada mensagem do loop e limitar turnos e gasto com as opções.

▶ Vídeo da aula ~1 min

Comece por aqui: um resumo animado e narrado. Clique no vídeo ou aperte Espaço para pausar.

1Por que importa

Até aqui você usou o Claude Code conversando com ele no terminal. O Claude Agent SDK entrega o mesmo motor (as mesmas ferramentas, o mesmo loop, o mesmo gerenciamento de contexto) como uma biblioteca para Python e TypeScript. Com ele, o agente vira parte do seu programa: um robô que organiza tarefas, revisa código ou responde a um sistema, sem ninguém digitando.

Você quer…Use
Trabalhar no dia a dia, conversando no terminalClaude Code (CLI): Módulos 1 a 9
Colocar o agente do Claude Code dentro do seu programa Python ou TypeScriptAgent SDK: este módulo
Chamar a API direto e escrever você mesmo o loop de ferramentasClient SDK (fora do escopo)
Custo e autorizaçãoO SDK usa uma chave de API da Anthropic, cobrada por uso: cada execução do agente gasta. Use a chave da sua conta pessoal de estudo, nunca a da empresa sem autorização. Uso em projeto da empresa só com aval da segurança da informação e da área responsável. Na dúvida sobre contrato, dados ou custos, procure essas áreas antes de rodar.

3Instalar e escrever o primeiro agente

Instalação (PowerShell, na pasta de treino)

O pacote se chama claude-agent-sdk e pede Python 3.10 ou mais novo. Na maioria das instalações ele já traz o Claude Code embutido. O passo a passo completo está no README da etapa 10.

PowerShellpython -m venv .venv .\.venv\Scripts\python.exe -m pip install claude-agent-sdk $env:ANTHROPIC_API_KEY = "sua-chave-aqui"
A chave é segredoTroque sua-chave-aqui pela sua chave só no terminal. Não escreva a chave em arquivo .py, README, print ou chat. O SDK não lê arquivos .env sozinho. A doc avisa que o login do claude.ai não serve para produtos feitos com o SDK: use chave de API (ou Amazon Bedrock, Google Cloud ou Microsoft Foundry, se a sua organização usa).

O menor agente possível

agente_loop.py (versão curta)import asyncio from claude_agent_sdk import query, ClaudeAgentOptions, ResultMessage async def main(): async for mensagem in query( prompt="Explique o que o tarefas.py faz.", options=ClaudeAgentOptions(allowed_tools=["Read", "Glob", "Grep"]), ): if isinstance(mensagem, ResultMessage) and mensagem.subtype == "success": print(mensagem.result) asyncio.run(main())
  • query() é assíncrona: devolve as mensagens aos poucos, e você as percorre com async for.
  • prompt é o pedido; options é um ClaudeAgentOptions com a configuração.
  • Você não executa as ferramentas: o SDK executa Read, Glob, Grep e devolve o resultado ao Claude.

As mensagens do loop

Classe (Python)Quando chega
SystemMessageEventos da sessão. O subtype "init" abre a sessão; "compact_boundary" avisa que houve compactação.
AssistantMessageUma para cada bloco da resposta: texto (TextBlock) ou chamada de ferramenta (ToolUseBlock).
UserMessageO resultado de cada ferramenta, que volta ao Claude.
StreamEventSó com include_partial_messages=True: pedacinhos de texto em tempo real.
ResultMessageO fim: texto final (result), subtype, num_turns, total_cost_usd e session_id.

Confira o tipo com isinstance(), importando as classes de claude_agent_sdk. Um turno é uma volta do loop: o Claude responde e, se pediu ferramentas, o SDK as executa e devolve os resultados.

O fim do loop: subtype da ResultMessage

subtypeO que houveTem result?
successTerminou normalmentesim
error_max_turnsBateu no limite de turnosnão
error_max_budget_usdBateu no teto de gastonão
error_during_executionUm erro interrompeu o loopnão
Envolva em tryQuando a query() termina num resultado de erro, ela entrega a ResultMessage e depois levanta uma exceção (de propósito). Coloque o async for num try/except para o script encerrar limpo.

As opções que você mais vai usar

Opção de ClaudeAgentOptionsPara quê
system_promptAs instruções fixas do agente (papel, idioma, regras).
allowed_toolsPré-aprova ferramentas: rodam sem pedir permissão. Não limita: as outras continuam existindo.
disallowed_tools / toolsTiram ferramentas do agente. Ex.: disallowed_tools=["Bash"] remove o Bash; tools=["Read", "Grep"] deixa só essas embutidas.
cwdA pasta de trabalho do agente (padrão: a pasta de onde o script rodou).
max_turnsMáximo de turnos. Sem limite por padrão.
max_budget_usdTeto de gasto estimado, em dólares. Sem limite por padrão. O valor 0 é recusado.
modelO modelo: um alias ("sonnet", "opus", "haiku") ou um ID completo. Sem ele, vale o modelo padrão do Claude Code.
effortQuanto o Claude raciocina: "low" a "max". Menos esforço, menos tokens.

conversa.py (trecho)async with ClaudeSDKClient(options=opcoes) as cliente: await cliente.query("Liste os comandos do TaskFlow.") async for mensagem in cliente.receive_response(): print(mensagem) await cliente.query("Agora resuma em uma linha.") # lembra da troca anterior async for mensagem in cliente.receive_response(): print(mensagem)

receive_response() entrega as mensagens até a ResultMessage daquela troca, inclusive. Você vai montar um agente assim na aula 4.

Streaming: texto em tempo real

Por padrão, cada AssistantMessage chega com o bloco completo. Para mostrar o texto enquanto é gerado, ligue include_partial_messages=True e trate o StreamEvent (de claude_agent_sdk.types): os eventos content_block_delta com delta do tipo text_delta trazem os pedaços de texto.

7Exercício real: o agente leitor do TaskFlow

Prepare a pasta de treino seguindo o README da etapa 10 (cópia fora do curso, ambiente virtual, pacote e chave só no terminal).

Este exercício gastaCada execução chama a API. Com as travas abaixo, o gasto de uma execução tende a ser pequeno, mas confira o valor estimado que o script imprime e acompanhe o consumo no console da sua conta.
  1. Na raiz da pasta de treino, crie agente_loop.py.
  2. Configure ClaudeAgentOptions com: um system_prompt em português pedindo resposta curta; allowed_tools só com Read, Glob e Grep; Bash, Write e Edit em disallowed_tools; cwd na pasta do script; max_turns=8; max_budget_usd=0.50.
  3. Peça: "Leia o tarefas.py e explique o que o TaskFlow faz e quais comandos ele tem."
  4. Imprima o texto de cada TextBlock, o nome de cada ToolUseBlock e, na ResultMessage, o subtype, o num_turns e o total_cost_usd.
  5. Rode com .\.venv\Scripts\python.exe agente_loop.py. Depois troque para max_turns=1 e veja o error_max_turns.
Ver o gabarito

Arquivo também em projeto-taskflow/etapa-10/gabarito/agente_loop.py.

agente_loop.pyimport asyncio from pathlib import Path from claude_agent_sdk import ( AssistantMessage, ClaudeAgentOptions, ResultMessage, TextBlock, ToolUseBlock, query, ) PASTA = Path(__file__).parent OPCOES = ClaudeAgentOptions( system_prompt=( "Você é o assistente do TaskFlow, uma CLI de tarefas em Python. " "Responda em português do Brasil, em no máximo 5 linhas. Não edite arquivos." ), allowed_tools=["Read", "Glob", "Grep"], # pré-aprovadas: só leitura disallowed_tools=["Bash", "Write", "Edit"], # nem aparecem para o Claude cwd=str(PASTA), # o agente trabalha nesta pasta max_turns=8, # trava contra loop longo max_budget_usd=0.50, # trava de gasto (estimado) ) async def main(): try: async for mensagem in query( prompt="Leia o tarefas.py e explique o que o TaskFlow faz e quais comandos ele tem.", options=OPCOES, ): if isinstance(mensagem, AssistantMessage): for bloco in mensagem.content: if isinstance(bloco, TextBlock): print(f"Claude: {bloco.text}") elif isinstance(bloco, ToolUseBlock): print(f"[ferramenta] {bloco.name}") elif isinstance(mensagem, ResultMessage): if mensagem.subtype == "success": print(f"\nResultado: {mensagem.result}") else: print(f"\nParou: {mensagem.subtype}") print(f"Turnos: {mensagem.num_turns}") if mensagem.total_cost_usd is not None: print(f"Custo estimado: US$ {mensagem.total_cost_usd:.4f}") except Exception as erro: # query() avisa com uma exceção depois de entregar um resultado de erro print(f"A sessão terminou com erro: {erro}") if __name__ == "__main__": asyncio.run(main())

Resultado esperado (ilustrativo): uma ou duas linhas [ferramenta] Read, um resumo citando adicionar, listar, concluir e remover, Turnos pequeno e um custo estimado de centavos. Com max_turns=1, aparece Parou: error_max_turns e, em seguida, a mensagem do except.

Por que total_cost_usd pode ser None? No Python, esse campo é opcional; confira antes de formatar. E lembre: é uma estimativa local, não a cobrança oficial.

8Erros comuns

"Not logged in" ou "Invalid API key"

A variável ANTHROPIC_API_KEY não está no terminal onde o script roda. Defina com $env: nessa mesma janela.

Achar que allowed_tools limita

Ele só pré-aprova. Para tirar uma ferramenta, use disallowed_tools ou tools.

Ler result sem olhar o subtype

result só existe no success. Confira o subtype antes.

Sem travas

Sem max_turns e max_budget_usd, um pedido aberto pode rodar muito e gastar além do previsto.
