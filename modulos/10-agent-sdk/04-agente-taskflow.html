Subagentes, custo e o agente TaskFlow

Objetivo: definir um subagente em código, acompanhar e limitar o custo do agente e montar o projeto final: um agente TaskFlow que conversa no terminal, usa as suas ferramentas, respeita a sua política e chama um revisor.

▶ Vídeo da aula ~1 min

Comece por aqui: um resumo animado e narrado. Clique no vídeo ou aperte Espaço para pausar.

1Por que importa

Um agente de verdade junta várias peças: conversa contínua, ferramentas do domínio, regras de segurança e, às vezes, ajudantes especializados. E roda com dinheiro de verdade. Nesta aula você junta as aulas 1 a 3 e aprende a enxergar e travar o custo antes que ele vire surpresa.

Antes de rodarO projeto final faz várias chamadas à API por mensagem (e o subagente faz as dele). Use a chave da sua conta pessoal de estudo, mantenha o orçamento baixo e acompanhe o consumo no console da sua conta. Em projeto da empresa: só com aval da segurança da informação e da área responsável.

3Subagentes, custo e limites

Subagente em código: AgentDefinition

No Módulo 7 o subagente era um arquivo em .claude/agents/. No SDK, a doc recomenda defini-lo no código, na opção agents. O Claude o chama pela ferramenta Agent, que precisa estar disponível (e, para não perguntar, em allowed_tools).

agente_taskflow.py (trecho)from claude_agent_sdk import AgentDefinition, ClaudeAgentOptions REVISOR = AgentDefinition( description="Revisa o código Python do TaskFlow. Use quando o usuário pedir revisão do código.", prompt="Você revisa o TaskFlow... Não edite nada.", tools=["Read", "Grep", "Glob"], # somente leitura model="haiku", # alias de um modelo menor ) opcoes = ClaudeAgentOptions( agents={"revisor-taskflow": REVISOR}, allowed_tools=["Read", "Glob", "Grep", "Agent"], )
CampoObrigatório?Para quê
descriptionsimQuando usar. O Claude decide a delegação por ela.
promptsimAs instruções (o system prompt) do subagente.
toolsnãoFerramentas permitidas. Se omitir, herda as disponíveis para subagentes.
modelnãoAlias ("haiku", "sonnet", "opus", "fable", "inherit") ou ID completo.

Há outros campos (maxTurns, effort, permissionMode…); no Python, os nomes de várias palavras ficam em camelCase, como na doc. Para saber se houve delegação, procure um ToolUseBlock com name "Agent" (versões antigas usavam "Task").

O que o subagente recebeSó o pedido que o Claude escreve na chamada da ferramenta Agent, as próprias instruções e as ferramentas. Não recebe o histórico da conversa. E devolve só o relatório final: o contexto do agente principal cresce pouco.

Custo: onde ver e o que significa

Campo da ResultMessageO que conta
total_cost_usdCusto estimado da chamada, com os subagentes.
model_usageTokens e custo por modelo, com os subagentes.
usageTokens só do loop principal (sem os subagentes).
Estimativa não é faturaO total_cost_usd é calculado no seu computador, com uma tabela de preços embutida no SDK. Pode divergir da cobrança real (mudança de preço, modelo novo). A doc é clara: use para acompanhar e orçar, nunca para cobrar alguém ou tomar decisão financeira. O valor oficial fica no console da sua conta.

Com o ClaudeSDKClient (entrada em fluxo), cada troca gera uma ResultMessage, e o total_cost_usd dela é o acumulado da conversa: leia o último, não some todos.

Travas de custo

TravaComo
Teto de gastomax_budget_usd. Conta os subagentes. Ao bater: error_max_budget_usd. A resposta que cruza o teto ainda termina, então deixe folga.
Limite de turnosmax_turns, contra loops longos.
Modelo menormodel="haiku" no subagente (ou no agente) para tarefas simples.
Menos raciocínioeffort="low" para tarefas de busca e listagem.
Profundidade e paralelismoPela opção env: CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH (padrão 3) e CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS (padrão 20).

Retomar depois

Toda ResultMessage traz o session_id. Guardando-o, uma nova query() com ClaudeAgentOptions(resume=session_id) continua a mesma conversa, com o contexto anterior.

7Exercício real: o agente TaskFlow

Na pasta de treino, com agente_ferramentas.py (aula 2) e agente_permissoes.py (aula 3) na raiz. Este exercício gasta mais que os anteriores: cada mensagem é uma rodada do loop.

  1. Crie agente_taskflow.py reaproveitando o servidor, o can_use_tool e os hooks da aula 3.
  2. Defina o subagente revisor-taskflow com AgentDefinition: somente leitura e model="haiku".
  3. Use tools=["Read", "Glob", "Grep", "Agent"], cwd na pasta do script, max_turns=15 e max_budget_usd=1.00.
  4. Abra uma conversa com ClaudeSDKClient num laço: leia a mensagem do terminal, envie com query(), imprima as respostas de receive_response() e o custo acumulado. sair encerra.
  5. Registre um hook SubagentStop que imprime quando o revisor termina.
  6. Converse: "liste minhas tarefas", "adicione 'Preparar café da reunião de teste'", "revise o código do TaskFlow", "agora conclua a tarefa 1". Observe o custo acumulado a cada troca.
Ver o gabarito

Arquivo em projeto-taskflow/etapa-10/gabarito/agente_taskflow.py (precisa dos dois scripts anteriores na mesma pasta).

agente_taskflow.pyimport asyncio from pathlib import Path from claude_agent_sdk import ( AgentDefinition, AssistantMessage, ClaudeAgentOptions, ClaudeSDKClient, ResultMessage, TextBlock, ToolUseBlock, ) from claude_agent_sdk.types import HookMatcher from agente_permissoes import SERVIDOR, auditar, bloquear_remocao, manter_fluxo, pode_usar PASTA = Path(__file__).parent REVISOR = AgentDefinition( description="Revisa o código Python do TaskFlow. Use quando o usuário pedir revisão do código.", prompt=( "Você revisa o TaskFlow (Python, só biblioteca padrão). Leia os arquivos .py e aponte, " "em até 5 itens: funções sem docstring, mensagens fora do português e riscos. Não edite nada." ), tools=["Read", "Grep", "Glob"], # somente leitura model="haiku", # alias: um modelo menor e mais barato para a revisão ) async def subagente_terminou(input_data, tool_use_id, context): print(f"[subagente] terminou: {input_data['agent_id']}") return {} OPCOES = ClaudeAgentOptions( system_prompt=( "Você é o agente do TaskFlow. Gerencie tarefas com as ferramentas mcp__taskflow__ e, " "para revisar código, use o subagente revisor-taskflow. Responda em português do Brasil." ), cwd=str(PASTA), mcp_servers={"taskflow": SERVIDOR}, tools=["Read", "Glob", "Grep", "Agent"], # embutidas disponíveis (sem Bash, Write, Edit) agents={"revisor-taskflow": REVISOR}, permission_mode="default", allowed_tools=[ "Read", "Glob", "Grep", "Agent", "mcp__taskflow__listar_tarefas", "mcp__taskflow__adicionar_tarefa", ], can_use_tool=pode_usar, # concluir: pergunta no terminal hooks={ "PreToolUse": [ HookMatcher(matcher="mcp__taskflow__remover_tarefa", hooks=[bloquear_remocao]), HookMatcher(matcher=None, hooks=[manter_fluxo]), ], "PostToolUse": [HookMatcher(matcher="^mcp__taskflow__", hooks=[auditar])], "SubagentStop": [HookMatcher(hooks=[subagente_terminou])], }, max_turns=15, # por mensagem max_budget_usd=1.00, # para a conversa toda (estimado) ) async def main(): print("Agente TaskFlow. Exemplos: 'liste minhas tarefas', 'revise o código'. Digite sair.") async with ClaudeSDKClient(options=OPCOES) as cliente: while True: texto = (await asyncio.to_thread(input, "\nvocê> ")).strip() if texto.lower() in ("sair", "exit"): break if not texto: continue await cliente.query(texto) async for mensagem in cliente.receive_response(): if isinstance(mensagem, AssistantMessage): for bloco in mensagem.content: if isinstance(bloco, TextBlock): print(f"agente> {bloco.text}") elif isinstance(bloco, ToolUseBlock): print(f"[ferramenta] {bloco.name}") elif isinstance(mensagem, ResultMessage): if mensagem.subtype != "success": print(f"[parou: {mensagem.subtype}]") if mensagem.total_cost_usd is not None: print(f"[custo acumulado estimado: US$ {mensagem.total_cost_usd:.4f}]") if __name__ == "__main__": asyncio.run(main())

Por que asyncio.to_thread(input, ...)? O input() trava o programa até você digitar. Rodá-lo numa thread evita travar o laço assíncrono do SDK.

Resultado esperado (ilustrativo): listar e adicionar rodam direto; "revise o código" mostra [ferramenta] Agent, depois [subagente] terminou: … e um resumo curto; concluir pede o seu s; o custo acumulado cresce a cada troca e o subagente entra na conta.

8Erros comuns

Esquecer a ferramenta Agent

Se tools não inclui Agent, o Claude não consegue delegar ao subagente.

Somar o custo de cada troca

Numa conversa com o cliente, o total_cost_usd já é acumulado. Somar conta duas vezes.

Confiar em usage para o total

usage não inclui os subagentes. Use total_cost_usd ou model_usage.

Teto sem folga

A resposta que cruza o max_budget_usd ainda termina. O gasto pode passar um pouco do teto.
