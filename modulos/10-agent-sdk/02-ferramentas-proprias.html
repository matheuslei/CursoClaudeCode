Ferramentas próprias

Objetivo: transformar funções Python do TaskFlow em ferramentas que o agente chama sozinho, com @tool e create_sdk_mcp_server, e controlar quais delas ele enxerga e usa sem perguntar.

▶ Vídeo da aula ~1 min

Comece por aqui: um resumo animado e narrado. Clique no vídeo ou aperte Espaço para pausar.

1Por que importa

As ferramentas embutidas (Read, Edit, Bash…) servem para qualquer projeto. Mas o seu sistema tem operações próprias: adicionar uma tarefa, consultar um cadastro, abrir um chamado. Dar uma ferramenta própria para cada operação deixa o agente mais seguro e previsível: ele chama a sua função, com os parâmetros certos, em vez de editar o tarefas.json na mão ou montar comandos no Bash.

🎯 Precisão

A descrição e os parâmetros dizem ao Claude exatamente o que a ferramenta faz e o que ela espera.

🔒 Controle

Você valida a entrada na função e decide o que fica disponível. Sem Bash, sem edição livre.

Lembra do Módulo 6?Lá, o servidor_mcp.py rodava como um processo separado, ligado ao Claude Code por claude mcp add. No SDK, o servidor MCP roda dentro do seu programa: nada de outro processo, nada de registrar com comando.

2Conceito: o caminho de uma chamada

3Anatomia de uma ferramenta

Uma ferramenta tem quatro partes: nome, descrição, esquema de entrada e a função (o handler). No Python, as três primeiras vão no decorador @tool:

agente_ferramentas.py (trecho)from typing import Any from claude_agent_sdk import tool, create_sdk_mcp_server from tarefas import carregar, salvar @tool("adicionar_tarefa", "Adiciona uma tarefa pendente. Use títulos curtos e fictícios.", {"titulo": str}) async def adicionar_tarefa(args: dict[str, Any]) -> dict[str, Any]: titulo = str(args.get("titulo", "")).strip() if not titulo: return {"content": [{"type": "text", "text": "Erro: título vazio."}], "is_error": True} tarefas = carregar() tarefas.append({"titulo": titulo, "feita": False}) salvar(tarefas) return {"content": [{"type": "text", "text": f"Tarefa {len(tarefas)} adicionada: {titulo}"}]} SERVIDOR = create_sdk_mcp_server(name="taskflow", version="1.0.0", tools=[adicionar_tarefa])
ParteO que é
NomeIdentificador único que o Claude usa na chamada ("adicionar_tarefa").
DescriçãoQuando e para que usar. É o que o Claude lê para decidir se chama. Escreva com cuidado.
Esquema de entradaUm dicionário nome → tipo ({"titulo": str}), que o SDK converte em JSON Schema. Para descrever um campo: Annotated[str, "texto"]. Para campo opcional, lista fechada (enum) ou faixa de valores, passe um JSON Schema completo.
HandlerFunção async que recebe args (já validados) e devolve um dicionário com content: uma lista de blocos, como {"type": "text", "text": "..."}.

Ligar o servidor ao agente

agente_ferramentas.py (opções)OPCOES = ClaudeAgentOptions( mcp_servers={"taskflow": SERVIDOR}, # a chave "taskflow" vira parte do nome tools=[], # tira as embutidas: só as do TaskFlow allowed_tools=["mcp__taskflow__*"], # pré-aprova todas deste servidor )
  • Nome completo: mcp__{servidor}__{ferramenta}, em que {servidor} é a chave que você deu em mcp_servers. Ex.: mcp__taskflow__adicionar_tarefa.
  • Curinga: mcp__taskflow__* pré-aprova todas as ferramentas desse servidor. Curinga só vale depois do prefixo literal: "*" ou "mcp__*" em allowed_tools são ignorados.
  • Disponível × aprovado: tools controla quais embutidas o Claude enxerga (tools=[] tira todas; as ferramentas MCP continuam). allowed_tools controla o que roda sem pedir permissão.

Anotações: só leitura roda em paralelo

agente_ferramentas.py (trecho)from claude_agent_sdk import ToolAnnotations @tool( "listar_tarefas", "Lista as tarefas do TaskFlow com número e status.", {"type": "object", "properties": {}}, # sem parâmetros: JSON Schema completo annotations=ToolAnnotations(readOnlyHint=True), # não altera nada ) async def listar_tarefas(args): ...

readOnlyHint=True permite ao SDK rodar a ferramenta em paralelo com outras de leitura (ferramentas próprias rodam uma de cada vez por padrão). É uma informação, não uma trava: se a função gravar no disco, ela grava. Mantenha a anotação honesta.

Erros: devolva, não derrube

O que aconteceO que o Claude vê
A função levanta uma exceção não tratadaA mensagem crua da exceção, como resultado de erro. O loop continua.
A função devolve "is_error": True com um textoA sua mensagem, com contexto ("a tarefa 9 não existe; liste primeiro"). O loop continua.
Busca de ferramentasPor padrão, o SDK adia o carregamento dos esquemas de ferramentas MCP e o Claude os busca quando precisa. Por isso, a saída pode mostrar uma chamada ToolSearch antes da sua ferramenta. É normal.
Só no TypeScriptA doc lista recursos de ferramentas próprias que existem só no SDK de TypeScript (por exemplo, a política permission_policy). No Python, o @tool repassa apenas content e is_error.

7Exercício real: ferramentas do TaskFlow

Use a pasta de treino da aula 1 (ambiente virtual e chave no terminal). Este exercício gasta: rode poucas vezes e confira o custo estimado.

  1. Na raiz da pasta de treino (ao lado de tarefas.py), crie agente_ferramentas.py.
  2. Escreva três ferramentas com @tool: listar_tarefas (sem parâmetros, readOnlyHint=True), adicionar_tarefa (titulo: str) e concluir_tarefa (numero: int). Reaproveite carregar() e salvar() do tarefas.py.
  3. Em concluir_tarefa, devolva is_error se o número não existir.
  4. Junte tudo com create_sdk_mcp_server(name="taskflow", ...), registre em mcp_servers, use tools=[], allowed_tools=["mcp__taskflow__*"] e as travas da aula 1.
  5. Peça: "Adicione as tarefas fictícias 'Revisar relatório de teste' e 'Organizar a mesa', conclua a primeira e me mostre a lista final." Imprima cada ToolUseBlock (nome e entrada).
  6. Confira com python tarefas.py listar que as tarefas foram gravadas de verdade.

agente_ferramentas.pyimport asyncio from typing import Any from claude_agent_sdk import ( AssistantMessage, ClaudeAgentOptions, ResultMessage, ToolAnnotations, ToolUseBlock, create_sdk_mcp_server, query, tool, ) from tarefas import carregar, salvar def _texto(msg: str, erro: bool = False) -> dict[str, Any]: """Monta o resultado no formato que o SDK espera (lista content).""" resultado: dict[str, Any] = {"content": [{"type": "text", "text": msg}]} if erro: resultado["is_error"] = True return resultado @tool( "listar_tarefas", "Lista as tarefas do TaskFlow com número e status ([x] feita, [ ] pendente).", {"type": "object", "properties": {}}, # sem parâmetros: JSON Schema completo annotations=ToolAnnotations(readOnlyHint=True), # só lê: pode rodar em paralelo ) async def listar_tarefas(args: dict[str, Any]) -> dict[str, Any]: tarefas = carregar() if not tarefas: return _texto("Nenhuma tarefa cadastrada.") linhas = [] for i, t in enumerate(tarefas, start=1): marca = "x" if t.get("feita") else " " linhas.append(f"{i}. [{marca}] {t['titulo']}") return _texto("\n".join(linhas)) @tool("adicionar_tarefa", "Adiciona uma tarefa pendente. Use títulos curtos e fictícios.", {"titulo": str}) async def adicionar_tarefa(args: dict[str, Any]) -> dict[str, Any]: titulo = str(args.get("titulo", "")).strip() if not titulo: return _texto("Erro: o título não pode ser vazio.", erro=True) tarefas = carregar() tarefas.append({"titulo": titulo, "feita": False}) salvar(tarefas) return _texto(f"Tarefa {len(tarefas)} adicionada: {titulo}") @tool("concluir_tarefa", "Marca como feita a tarefa de número informado (começa em 1).", {"numero": int}) async def concluir_tarefa(args: dict[str, Any]) -> dict[str, Any]: tarefas = carregar() numero = int(args.get("numero", 0)) if numero < 1 or numero > len(tarefas): return _texto(f"Erro: a tarefa {numero} não existe. Liste as tarefas primeiro.", erro=True) tarefas[numero - 1]["feita"] = True salvar(tarefas) return _texto(f"Tarefa {numero} concluída.") SERVIDOR = create_sdk_mcp_server( name="taskflow", version="1.0.0", tools=[listar_tarefas, adicionar_tarefa, concluir_tarefa], ) OPCOES = ClaudeAgentOptions( system_prompt="Você gerencia a lista do TaskFlow. Responda em português do Brasil, em poucas linhas.", mcp_servers={"taskflow": SERVIDOR}, tools=[], allowed_tools=["mcp__taskflow__*"], max_turns=10, max_budget_usd=0.50, ) async def main(): pedido = ( "Adicione as tarefas fictícias 'Revisar relatório de teste' e " "'Organizar a mesa', conclua a primeira e me mostre a lista final." ) try: async for mensagem in query(prompt=pedido, options=OPCOES): if isinstance(mensagem, AssistantMessage): for bloco in mensagem.content: if isinstance(bloco, ToolUseBlock): print(f"[ferramenta] {bloco.name}({bloco.input})") elif isinstance(mensagem, ResultMessage): if mensagem.subtype == "success": print(f"\n{mensagem.result}") else: print(f"\nParou: {mensagem.subtype}") if mensagem.total_cost_usd is not None: print(f"Custo estimado: US$ {mensagem.total_cost_usd:.4f}") except Exception as erro: print(f"A sessão terminou com erro: {erro}") if __name__ == "__main__": asyncio.run(main())

Resultado esperado (ilustrativo): chamadas mcp__taskflow__adicionar_tarefa (duas), mcp__taskflow__concluir_tarefa({'numero': 1}) e mcp__taskflow__listar_tarefas({}), e a lista final com a primeira marcada [x]. O número da tarefa depende do que já havia no seu tarefas.json.

8Erros comuns

Nome errado em allowed_tools

Escrever adicionar_tarefa em vez de mcp__taskflow__adicionar_tarefa: a regra não casa e a chamada cai no fluxo de permissão.

Esquecer o async

O handler precisa ser async def e devolver o dicionário com content.

Descrição vaga

"Faz coisas com tarefas" não ajuda o Claude a escolher. Diga o que faz, o que espera e quando usar.

Deixar a exceção estourar

Funciona, mas o Claude recebe uma mensagem crua. Prefira is_error com um texto útil.
