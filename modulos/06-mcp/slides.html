MCP em uma frase

Um padrão aberto para ligar o Claude a ferramentas e dados externos, como uma tomada universal.

  • 🛠 tools: ações que o Claude chama
  • 📄 resources: dados com @servidor:protocolo://caminho
  • 💬 prompts: viram comandos no menu /

Transportes

  • stdio: programa local iniciado pelo Claude Code (padrão)
  • http: serviço hospedado numa URL (recomendado para remotos)
  • sse: depreciado; prefira http

Adicionar e gerenciar

claude mcp add --transport http claude-code-docs https://code.claude.com/docs/mcp claude mcp add playwright -- npx -y @playwright/mcp@latest claude mcp list claude mcp get <nome> claude mcp remove <nome>

O -- separa as opções do Claude Code do comando do servidor.

Escopos

  • local (padrão): só você, só este projeto
  • project: .mcp.json no Git, para o time (cada um aprova)
  • user: só você, todos os projetos

Login OAuth: /mcp → Authenticate, ou claude mcp login <nome>

Seu servidor em Python

from mcp.server import MCPServer mcp = MCPServer("taskflow") @mcp.tool() def listar_tarefas() -> str: """Docstring = descrição para o Claude.""" ... mcp.run(transport="stdio")

Sem print() num servidor stdio! (SDK v2: FastMCP virou MCPServer)

Segurança

  • Só conecte servidores em que você confia
  • Conteúdo externo pode trazer prompt injection
  • Comece com leitura; credenciais somente leitura
  • Dados corporativos: decisão da segurança da informação e da privacidade (LGPD)
  • Remova o que não usa: menos contexto, menos risco

Um motor, várias superfícies

  • CLI: explícito, scriptável
  • VS Code: diffs lado a lado, Alt+K para linhas, plano comentável
  • Desktop: sessões paralelas, diffs com comentários, navegador embutido
  • Iguais em todas: CLAUDE.md, settings, MCP, skills · trocar: /desktop, /ide, /resume
